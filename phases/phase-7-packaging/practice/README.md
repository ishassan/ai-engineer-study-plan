# System design practice

Week 28, step 1 of the [study plan](../../../README.md#week-28-system-design-practice): work through four agent designs aloud, about 45 minutes each.

| Sheet | The design |
| --- | --- |
| [bank-knowledge-assistant.md](bank-knowledge-assistant.md) | A bank knowledge assistant |
| [erp-process-agent.md](erp-process-agent.md) | An ERP process agent |
| [analytics-agent.md](analytics-agent.md) | An analytics agent |
| [on-call-agent.md](on-call-agent.md) | An on-call agent |

Each sheet has the prompt as an interviewer gives it, the questions to ask before you design, a time plan for 45 minutes, and the points that a strong answer covers. Each point links to the part of your capstone that is evidence for it, so you can say "I built this, and here is what I measured". The sheets do not give an answer: the design is your work.

How to practise:

1. Set a timer for 45 minutes. Read only the prompt, then speak. Record yourself, or ask a friend to play the interviewer.
2. Draw the design on paper or in a drawing tool while you speak. Say each arrow as a sentence: "each tool call goes through the gateway" is a claim that the interviewer can test.
3. After the timer, compare what you said with the list of points. Mark each point that you missed, and read its evidence in your capstone again.
4. Do the same design again a few days later, with the points that you missed.
